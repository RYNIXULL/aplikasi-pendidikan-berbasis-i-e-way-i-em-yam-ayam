**Version:** 1.0

**Internal Base URL:** `/internal/v1` (Python + FastAPI — Private Network Only)

## 1. Global API Conventions

### 1.1. Standard Headers

| Header | Scope | Requirement |
|---|---|---|
| `Authorization` | Public `/api/v1` | `Bearer <accessToken>` on all protected endpoints |
| `Content-Type` | Both | `application/json` (or `multipart/form-data` for `POST /documents`) |
| `X-Request-Id` | Both | Optional client UUID; generated by server if omitted and echoed in responses |
| `Idempotency-Key` | Public POST mutations | Recommended on `/ai/generate`, `/assessments/:id/attempts`, `/games/:materialId/sessions` |
| `X-Internal-Service-Token` | Internal `/internal/v1` | Shared high-entropy internal service secret |
| `X-Internal-Signature` | Internal `/internal/v1` | `HMAC-SHA256(timestamp + "." + rawBody)` with `X-Internal-Timestamp` (<= 60s skew) |

### 1.2. Response Envelopes

**Success Envelope:**
```json
{
  "success": true,
  "data": {},
  "meta": {
    "requestId": "9f8c1e34-6b2d-4c8d-a245-1c4352f2f10a",
    "timestamp": "2026-11-20T14:30:00.000Z",
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 42,
      "totalPages": 3
    }
  }
}
```
(`meta.pagination` is included only on paginated list responses.)

**Error Envelope:**
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed.",
    "details": [
      {
        "field": "questionCount",
        "issue": "Must be between 1 and 50"
      }
    ]
  },
  "meta": {
    "requestId": "9f8c1e34-6b2d-4c8d-a245-1c4352f2f10a",
    "timestamp": "2026-11-20T14:30:00.000Z"
  }
}
```

### 1.3. Standardized Error Code Catalog

| HTTP Status | Error Code | Trigger Condition |
|---|---|---|
| `400` | `VALIDATION_ERROR` | Invalid query/body/params schema |
| `400` | `FILE_INTEGRITY_FAILED` | Magic bytes mismatch, corrupt archive, or zip-bomb signature |
| `400` | `DOCUMENT_NOT_READY` | Attempted generation on a document whose status is not `READY` |
| `400` | `CONTENT_NOT_APPROVED` | Attempted publishing a `DRAFT` or `IN_REVIEW` content to a classroom |
| `401` | `AUTH_INVALID_CREDENTIALS` | Wrong email or password |
| `401` | `AUTH_TOKEN_EXPIRED` | Access JWT expired |
| `401` | `AUTH_TOKEN_INVALID` | Missing, malformed, or invalid JWT/refresh token |
| `401` | `AUTH_TOKEN_REUSED` | Previously rotated refresh token replayed (entire token family revoked) |
| `403` | `FORBIDDEN` | Role mismatch or ownership/enrollment check failed |
| `404` | `NOT_FOUND` | Resource missing or outside caller's access scope |
| `404` | `CLASSROOM_CODE_INVALID` | Classroom join code does not match an active open classroom |
| `409` | `CONFLICT` | Duplicate email, already enrolled, or state transition conflict |
| `409` | `DUPLICATE_SUBMISSION` | Attempt already submitted or `max_attempts` exhausted |
| `409` | `ASSESSMENT_CLOSED` | Assessment outside `available_from..available_until` or status `CLOSED` |
| `413` | `FILE_TOO_LARGE` | Upload exceeds 25 MB limit |
| `415` | `UNSUPPORTED_MEDIA_TYPE` | File format other than PDF, DOCX, or PPTX |
| `429` | `RATE_LIMIT_EXCEEDED` | Endpoint rate limit triggered |
| `429` | `AI_QUOTA_EXCEEDED` | Daily or monthly AI token/job quota reached for teacher |
| `502` | `AI_GENERATION_FAILED` | Upstream AI provider or validation pipeline failed after retries |
| `500` | `INTERNAL_ERROR` | Unhandled server error (stack traces never exposed to client) |

### 4.8. `Game` Configurations (6 Template Types)

All 6 types share the envelope `{ "game_type", "title", "instructions", "settings": { "time_limit_seconds", "shuffle" }, "max_possible_score", "source_references" }`:

1. **`quiz_battle`:** `rounds`: `[{ id, question, options, correct_answer, points, time_seconds, explanation, source_reference }]`
2. **`word_matching`:** `items`: `[{ id, left, right, points, source_reference }]` (min 4, max 12 pairs)
3. **`true_false`:** `items`: `[{ id, statement, is_true, explanation, points, source_reference }]`
4. **`memory_cards`:** `pairs`: `[{ id, card_a, card_b, source_reference }]` (even count 4–10 pairs)
5. **`crossword`:** `grid_size`: `{ rows, cols }`, `entries`: `[{ number, direction ("across"|"down"), row, col, answer (UPPERCASE A-Z no spaces), clue, source_reference }]` — Python validator verifies all grid intersections are collision-free before returning!
